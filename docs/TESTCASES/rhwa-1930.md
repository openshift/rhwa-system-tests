## 2. Summary

After deployment, SNR DaemonSet pods must not set `hostPort` on any container
port. This validates the fix for DAST finding KSV024 (AVD-KSV-0024): per the
pod security standard "Host Ports", hostPorts should be disallowed or restricted
to a known list.

## 3. Scope

- **In scope**: Verifying that every SNR DaemonSet agent pod's container port
  spec has `hostPort` equal to zero.
- **Out of scope**: The DaemonSet manifest itself (covered by the upstream fix
  in medik8s/self-node-remediation#316); other DAST findings; pod security
  admission enforcement.
